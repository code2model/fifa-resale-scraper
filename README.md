# FIFA Resale Scraper

This repository contains a proof of concept for tracking FIFA resale availability data from the FIFA resale site.

## What this project does

- Attaches to a real Chrome session
- Captures the FIFA resale availability API response
- Saves the raw JSON output locally
- Keeps the data ready for the next parsing and storage step

## Current scope

This repo currently covers **Layer 1** only:

- category
- block
- availability_resale
- min_price
- max_price

The next phase will be seat-level extraction and database insertion.

## Repository structure

- `main.py`  
  Main scraper script. Connects to an existing Chrome session, captures the availability API, and saves the response.

- `.env`  
  Stores local configuration such as the target URL and polling interval.

- `requirements.txt`  
  Python dependencies needed to run the scraper.

- `availability_output.json`  
  Raw output file generated by the scraper.

- `README.md`  
  Project overview and run instructions.

## Requirements

- Python 3.11+
- Google Chrome
- Playwright
- A logged-in FIFA resale browser session already open in Chrome

## Setup

Install the Python packages:

```bash
pip install -r requirements.txt
```

Install Playwright browsers:

```bash
python -m playwright install
```

## `.env` example

```env
TARGET_URL=https://fwc26-resale-usd.tickets.fifa.com/secure/selection/event/seat/performance/10229225516056/lang/en
POLL_SECONDS=60
```

## How the flow works

1. Open Chrome manually and keep the FIFA resale session active.
2. Run `main.py`.
3. The script connects to the Chrome session through CDP.
4. It reloads the page to trigger the availability API.
5. The response is captured and saved into `availability_output.json`.

## Run the scraper

Start Chrome with remote debugging enabled:

```bash
chrome.exe --remote-debugging-port=9222 --user-data-dir="C:\chrome_profile"
```

Then run the scraper:

```bash
python main.py
```

## Output

The scraper writes the captured JSON response to:

```text
availability_output.json
```

This file can then be used for the next parsing step.

## Notes

- This is a POC scraper, not the final production version.
- The current output is block-level availability data.
- Seat-level extraction and Supabase insertion will be added in the next phase.
